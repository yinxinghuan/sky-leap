# 角色衣柜宿主高度兼容复验

## 首轮发现

- P0 · `390×630`：角色舞台不可收缩，底部“正在使用”与“继续跳”超出 `.shop-sheet`，被 `overflow: hidden` 裁掉。
- 影响：AlterU 顶部区域增高后，游戏获得的中等高度视口落在旧的 `621–820 px` 响应式空档，玩家无法关闭衣柜或继续游戏。

## 修复

- `.shop-sheet` 以宿主实际内容高度为上限。

- 紧凑间距断点由 `620 px` 扩展到 `720 px`。
